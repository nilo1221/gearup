## Deploy su GitHub

1. Crea un nuovo repository vuoto su `https://github.com/nilo1221` (es. `gearup-landing`).
2. Esegui:

```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/nilo1221/gearup.git
git branch -M main
git push -u origin main
```

## Deploy su Vercel

1. Vai su [https://vercel.com](https://vercel.com) e fai login.
2. Clicca **Add New Project** → importa il repository GitHub.
3. Lascia le impostazioni di default (Framework Preset: **Other** o rileva automaticamente).
4. Clicca **Deploy**.

Vercel assegnerà un dominio tipo `https://gearup-landing-xxxx.vercel.app`.
